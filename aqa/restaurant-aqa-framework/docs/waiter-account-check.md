## Що налаштовано

Створено окремий AQA-акаунт офіціанта для локації 9 Abashidze Street.
Акаунт створено в Cognito без надсилання листа. Для додавання ролі Waiter
і запису в таблиці Waiters використано наявний API застосунку POST /waiters.
Ідентифікатор sub із токена відповідає userId у таблиці Waiters.

Згенерований пароль збережено лише в локальному .env із правами 600.
Заповнено WAITER_USERNAME, WAITER_PASSWORD, TESTTABLE_ID,
TESTTABLE_WAITER_USERNAME та TESTTABLE_WAITER_PASSWORD.
ADMIN_* залишені порожніми: адміністратор для цих перевірок не потрібен.

Тестовий стіл: demo-table-7d598da3-0887-4a04-a3a1-fe26d8a4a4f2-1.
Його locationId відповідає локації офіціанта.

призначення для сценаріїв офіціанта.
