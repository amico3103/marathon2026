# Технології проєкту

Це вебзастосунок для ресторану: відвідувачі можуть переглядати меню, бронювати столики й робити замовлення, а працівники — керувати ними та переглядати звіти. Проєкт складається з інтерфейсу в браузері, серверної частини й ресурсів AWS.

## Інтерфейс: `frontend/restaurant-frontend-app`

| Технологія | Для чого використовується |
| --- | --- |
| **HTML і SCSS** | Розмітка сторінок і оформлення. SCSS допомагає впорядковувати стилі. |
| **TypeScript 6.0** | Мова, якою написана логіка інтерфейсу. |
| **Angular 22.1** | Основний фреймворк: збирає сторінки з компонентів, перемикає розділи сайту та надсилає запити до API. |
| **Angular Material і CDK 22.1** | Готові елементи інтерфейсу та інструменти для їх побудови, зокрема сповіщення. |
| **RxJS 7.8** | Допомагає працювати з відповідями сервера та іншими асинхронними подіями. |
| **Day.js і ngx-daterangepicker-bootstrap** | Робота з датами звітів і налаштування вибору діапазону дат. |
| **qr-code-styling** | Створення QR-кодів у браузері. |
| **Node.js і npm** | Встановлення залежностей, локальний запуск і збирання сайту. У `package.json` зазначено Node.js 22 або 24. |

Для входу інтерфейс працює з токенами користувача; у залежностях є `@auth0/angular-jwt`. Стилі та файли компонентів лежать у `src/app`, а конфігурація збірки — в `angular.json`.

## Серверна частина: `backend/restaurant-backend-app`

| Технологія | Для чого використовується |
| --- | --- |
| **C# і .NET 10** | Мова та платформа, на яких написана серверна логіка. |
| **AWS Lambda** | Запускає серверний код у вигляді окремих функцій. У проєкті є функція API, обробник даних для звітів і функція надсилання звітів. |
| **Amazon API Gateway** | Приймає HTTP-запити від сайту й передає їх функції API. |
| **Amazon DynamoDB** | База даних для закладів, страв, столиків, бронювань, замовлень, відгуків і звітів. |
| **Amazon Cognito** | Реєстрація, вхід і облікові записи користувачів. Для захищених запитів перевіряються токени користувачів. |
| **Amazon S3** | Зберігання зображень страв, закладів і профілів. |
| **Amazon SQS** | Черга повідомлень для обробки даних звітів у фоновому режимі. |
| **Amazon SES** | Надсилання звітів електронною поштою. |
| **Amazon EventBridge Scheduler** | Запускає функцію надсилання щотижневих звітів за розкладом. |

Для створення файлів звітів код використовує **QuestPDF** (PDF) і **NPOI** (Excel `.xls`), також може створювати CSV. Для обробки зображень використовується **ImageSharp**. Опис API є в [`docs/ApiRoutes.md`](backend/restaurant-backend-app/docs/ApiRoutes.md); для його перегляду також підготовлено **Swagger UI**.

## Розміщення та інструменти розробки

| Технологія | Для чого використовується |
| --- | --- |
| **Amazon S3 + CloudFront** | Зібраний сайт зберігається в S3, а CloudFront доставляє його користувачам через HTTPS. |
| **AWS IAM** | Задає права доступу функцій і розкладу до потрібних сервісів AWS. |
| **Terraform 1.10+** | Описує ресурси AWS у файлах `infra/terraform`: зокрема сховища, CloudFront, Cognito, чергу й розклад. |
| **AWS Syndicate** | Збирає та розгортає серверні Lambda-функції й API Gateway. |
| **Python** | Потрібен для AWS Syndicate та скрипту заповнення демонстраційних даних `infra/seed_demo_data.py`. |
| **AWS CLI** | Допомагає налаштовувати AWS і завантажувати зібраний сайт. |
| **Jasmine і Karma; xUnit і Moq** | Інструменти для перевірки коду інтерфейсу та серверної частини відповідно. |
| **ESLint і Prettier** | Перевірка стилю коду та його форматування в інтерфейсі. |

## Як усе працює разом

1. Користувач відкриває сайт: CloudFront віддає файли інтерфейсу із S3.
2. Angular надсилає запит до API Gateway, наприклад щоб отримати меню або створити бронювання.
3. API Gateway викликає функцію Lambda, написану на C#. Вона працює з DynamoDB, Cognito та S3 і повертає відповідь сайту.
4. Дані для звітів можуть надходити через SQS до окремої функції Lambda. За розкладом EventBridge запускає надсилання звітів через SES.

Основні файли для перевірки версій і налаштувань: [`package.json`](frontend/restaurant-frontend-app/package.json), [`APIHandler.csproj`](backend/restaurant-backend-app/dnapp/lambdas/api-handler/APIHandler.csproj), [`deployment_resources.json`](backend/restaurant-backend-app/deployment_resources.json) і файли в [`infra/terraform`](infra/terraform).
